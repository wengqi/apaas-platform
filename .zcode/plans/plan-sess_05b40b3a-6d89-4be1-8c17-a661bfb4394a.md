# 条件求值统一方案 — JsonLogic + RAQB 技术栈统一（无旧数据兼容）

## 背景

项目当前有 5 套条件表示形式，其中两套翻译器是近乎重复的代码。系统处于开发阶段，**无需旧数据兼容**，可直接替换格式、删除旧类型和旧代码。

### 当前碎片化 → 目标状态

| # | 模块 | 当前 | 目标 |
|---|------|------|------|
| 1 | 流程条件分支 | JsonLogic JSON + RAQB ✅ | 不变 |
| 2 | 视图筛选 | `{fieldId, operator, value}` + AND/OR，手写表单 | JsonLogic + RAQB |
| 3 | 行级 ABAC 权限 | `ConditionExpr` DSL，无编辑 UI | JsonLogic + RAQB 编辑器 |
| 4 | API 查询 filter | 扁平数组 `[{field, operator, value}]` | JsonLogic JSON |
| 5 | 公式字段 | expr-eval 字符串 | 不变（值计算 ≠ 谓词判定）|

## Phase 1：共享 JsonLogic→Prisma 翻译器（后端）

**新建 `apps/gateway/src/shared/jsonlogic-to-prisma.ts`**

```ts
export function jsonLogicToPrismaWhere(
  rule: object | null | undefined,
  variables?: Record<string, string>,  // { currentUser: 'user_xxx' }
): Prisma.RecordWhereInput | null
```

JsonLogic → Prisma 映射：

| JsonLogic | Prisma WHERE |
|-----------|-------------|
| `{"and": [...]}` | `{ AND: [...] }` |
| `{"or": [...]}` | `{ OR: [...] }` |
| `{"!": {...}}` | `{ NOT: {...} }` |
| `{">": [{"var":"f"}, v]}` | `{ data: { path:["f"], gt:v } }` |
| `{"==": [{"var":"f"}, v]}` | `{ data: { path:["f"], equals:v } }` |
| `{"in": ["substr", {"var":"f"}]}` | `{ data: { path:["f"], string_contains:"substr" } }` |
| `{"in": [{"var":"f"}, [v1,v2]]}` | `{ OR: [{data:{path:["f"],equals:v1}}, ...] }` |
| `{"!":{"var":"f"}}` | 空/null 检测 |
| `{"!!":{"var":"f"}}` | 非空检测 |

**`"in"` 操作符歧义处理**：根据第一个参数是否为 `{var:...}` 区分——是则属于集合（IN），否则字符串包含（contains）。

**变量替换**：`{"var":"__currentUser"}` → 从 `variables` 映射取值，用于行级权限的 `${currentUser}` 场景。

**新建 `apps/gateway/src/shared/jsonlogic-to-prisma.spec.ts`** — 覆盖所有操作符、嵌套 AND/OR/NOT、变量替换、空规则。

## Phase 2：重写权限条件翻译器（后端）

**改写 `apps/gateway/src/permission/condition-translator.ts`**

删除全部旧代码（`translateExpr`、`translateItem`、`resolveValue`、`ConditionItem`、`ConditionExpr` 接口），替换为：

```ts
import { jsonLogicToPrismaWhere } from '../shared/jsonlogic-to-prisma.js';

export type VariableMap = Record<string, string>;

export function translateCondition(
  condition: object | null | undefined,
  variables: VariableMap,
): Prisma.RecordWhereInput | null {
  return jsonLogicToPrismaWhere(condition, variables);
}
```

`record.service.ts` 中调用方不变（`translateCondition(condition, { currentUser })`）。

## Phase 3：重写视图筛选 + API filter（后端）

**改写 `apps/gateway/src/record/record.service.ts`**

- 删除 `buildCondition()` 方法（~80 行重复代码）
- 删除 `FilterCondition` 接口
- `parseFilter()` 改为：解析 JSON 字符串为 object，直接调用 `jsonLogicToPrismaWhere()`
- `query()` 中视图筛选和权限条件都通过共享翻译器处理：

```ts
// 视图筛选
if (params.filter) {
  const rule = JSON.parse(params.filter);
  const where = jsonLogicToPrismaWhere(rule);
  if (where) where.AND = [where];
}

// 权限条件
if (permissionContext?.condition) {
  const conditionWhere = translateCondition(permissionContext.condition, { currentUser });
  // 合并到 where.AND
}
```

API `filter` 参数格式从扁平数组改为 JsonLogic JSON 字符串。
