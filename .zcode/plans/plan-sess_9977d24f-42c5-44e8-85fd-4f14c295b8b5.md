# 流程引擎单模式化 — 清除双模式/BPMN 残留

## 背景

项目决策：流程引擎只保留一种模式（飞书 aPaaS 方案 = flowgram.ai Fixed Layout + WorkflowSchema SSOT）。需要清除所有"双模式"、"BPMN 互操作"、"标准模式/简化模式"的残留。

**关键事实**：双模式/BPMN 在代码中从未真正落地（无 bpmn-js 依赖、无转换器代码、无标准模式编辑器组件），但文档中大量描述了这套架构。shared 类型层已收敛为单模式。
