# 统一前端状态管理 — 详细实施计划

## 目标

统一到 **Zustand + React Query 双层架构**，消除 Context 状态管理和 react-redux 僵尸依赖。

## 三阶段总览

```
P0（消除技术栈冗余）— 移除 react-redux + RuntimeStore 迁移到 Zustand scoped store
P1（消除代码重复）— auth/RuntimeStore/expression-engine/action-executor/QueryClient 提到 @apaas/shared/stores
P2（统一编辑器模式）— pageBuilder/processEditor 撤销栈统一为 createHistory<T>()
```

### P0-Step 2：RuntimeStore 从 Context 迁移到 Zustand scoped store

两个包的 RuntimeStore 代码几乎逐字相同，本步骤仅改架构（Context→Zustand），P1 再提到 shared。

**核心变更模式**：

```
Before: createContext<RuntimeContext>(DEFAULT_RUNTIME)
        useState(vm) + useRef(vmRef) + useMemo(value)
        useContext(RuntimeContext) → 返回整个 context value

After:  createStore<RuntimeState>((set, get) => ({...}))  ← Zustand scoped store
        createContext<StoreApi<RuntimeState>>(null!)      ← Context 只传 store 引用
        useStore(useRuntimeStore(), selector)              ← 精确订阅
```

**修改 `packages/studio/src/components/page-builder/RuntimeStore.tsx`**（重写）：

```tsx
import { createContext, useContext, useEffect, useRef, useState, type ReactNode } from 'react';
import { createStore, useStore, type StoreApi } from 'zustand';
// ... 保留 initVm / setByPath / stripVmPrefix / isPlainObjectLiteral 工具函数不变

// State 类型（与原 RuntimeContext 结构一致，去掉函数值的包装）
interface RuntimeState {
  vm: Record<string, unknown>;
  setVariable: (path: string, value: unknown) => void;
  queryData: (variableName: string) => Promise<void>;
  executeAction: (action: ActionConfig) => Promise<void>;
  executeActions: (actions: ActionConfig[]) => Promise<void>;
}

// Context 传递 store 实例引用（不是状态值）
const RuntimeStoreContext = createContext<StoreApi<RuntimeState> | null>(null);

// Provider：每次挂载创建独立 store 实例
export function RuntimeStoreProvider({ viewModel, objectId, children }) {
  const navigateImpl = useNavigate();
  const { appId } = useParams();

  const [store] = useState(() =>
    createStore<RuntimeState>((set, get) => ({
      vm: initVm(viewModel),
      setVariable: (path, value) => set((s) => ({ vm: setByPath(s.vm, path, value) })),
      queryData: async (variableName) => { /* 用 get().vm 读最新值 */ },
      executeAction: async (action) => { /* 用 get() 读 vm，调 action-executor */ },
      executeActions: async (actions) => { /* 同上 */ },
    }))
  );

  // autoQuery effect（挂载时触发）
  useEffect(() => {
    for (const [key, def] of Object.entries(viewModel.variables)) {
      if (def.datasource?.autoQuery) void store.getState().queryData(key);
    }
  }, [store, viewModel]);

  return <RuntimeStoreContext.Provider value={store}>{children}</RuntimeStoreContext.Provider>;
}

// 消费 hook：返回 store 实例
export function useRuntimeStore(): StoreApi<RuntimeState> {
  const store = useContext(RuntimeStoreContext);
  if (!store) {
    // 编辑模式 no-op：返回一个静态 no-op store
    return noopStore;
  }
  return store;
}

// 精确订阅 hook（消费方用这个）
export function useRuntimeCtx<T>(selector: (s: RuntimeState) => T): T {
  return useStore(useRuntimeStore(), selector);
}
```

**关键设计**：
- `noopStore`：一个模块级静态 store，所有方法为 no-op，编辑模式安全（替代原 `DEFAULT_RUNTIME`）
- `useRuntimeCtx(selector)` 改为接收 selector，消费方从 `const { vm } = useRuntimeCtx()` 改为 `const vm = useRuntimeCtx(s => s.vm)`
- `queryData`/`executeAction` 内部用 `get().vm` 读最新值，替代原来的 `vmRef.current` 模式
- `navigate` 用 `useRef` 持有（Zustand store 创建时无法访问 hook，需在 Provider 中将 navigate 注入 store）

**消费方修改**（studio `ComponentRenderer.tsx`）：
```tsx
// Before
const runtime = useRuntimeCtx();
const vm = runtime.vm;
runtime.setVariable(...)

// After
const vm = useRuntimeCtx(s => s.vm);
const setVariable = useRuntimeCtx(s => s.setVariable);
// 或整体（少量场景）
const { setVariable, executeAction } = useRuntimeCtx(s => ({ setVariable: s.setVariable, executeAction: s.executeAction }));
```

**同样修改 `packages/runtime-ui/src/runtime/RuntimeStore.tsx`**（同样模式）

**消费方修改**（runtime-ui `ComponentRenderer.tsx`、`PageView.tsx`）

```ts
import { create } from 'zustand';
import { persist } from 'zustand/middleware';

export const useAuthStore = create<AuthState>()(
  persist(
    (set) => ({
      token: null,
      user: null,
      login: (token, user) => set({ token, user }),
      logout: () => set({ token: null, user: null }),
    }),
    {
      name: 'apaas:auth',        // 统一存储键
      // 旧键迁移：onRehydrateStorage 检测 apaas:token/apaas_runtime_token
      onRehydrateStorage: () => (state) => {
        if (!state?.token) {
          // 尝试从旧键迁移
          const oldToken = localStorage.getItem('apaas:token') ?? localStorage.getItem('apaas_runtime_token');
          const oldUser = localStorage.getItem('apaas:user') ?? localStorage.getItem('apaas_runtime_user');
          if (oldToken && oldUser) {
            state?.login(oldToken, JSON.parse(oldUser));
            localStorage.removeItem('apaas:token');
            localStorage.removeItem('apaas:user');
            localStorage.removeItem('apaas_runtime_token');
            localStorage.removeItem('apaas_runtime_user');
          }
        }
      },
    },
  ),
);
```

```ts
export function initAuthFromHash(): void {
```

## P2：统一编辑器撤销/重做模式（studio 内部，低优先级）

### P2-Step 1：createHistory 工具函数

**新建 `packages/studio/src/stores/create-history.ts`**：
```ts
export interface HistoryStack<T> {
  past: T[];
  future: T[];
  push: (snapshot: T) => void;
  undo: () => T | null;
  redo: () => T | null;
  canUndo: () => boolean;
  canRedo: () => boolean;
  clear: () => void;
}

export function createHistory<T>(limit = 50): HistoryStack<T> {
  let past: T[] = [];
  let future: T[] = [];
  return {
    past, future,
    push: (snapshot) => { past = [...past, snapshot].slice(-limit); future = []; },
    undo: () => { const prev = past.pop(); if (prev) { future = [...future, prev]; return prev; } return null; },
    redo: () => { const next = future.pop(); if (next) { past = [...past, next]; return next; } return null; },
    canUndo: () => past.length > 0,
    canRedo: () => future.length > 0,
    clear: () => { past = []; future = []; },
  };
}
```

### P2-Step 2：pageBuilder + processEditor 统一

- `pageBuilder.ts`：用 `createHistory<PageSchema>()` 替换 `past`/`future`，增加 `dirty` + `markSaved()`
- `processEditor.ts`：用 `createHistory<WorkflowSchema>()` 替换手写栈，保留 `dirty` + `markSaved()`
- 统一上限 50
