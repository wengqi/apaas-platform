# ADR-0006: 页面层翻案——AI 自由写码 + 沙箱运行 + manifest 数据治理

- 状态：已接受（2026-11-05～11-07 grilling 两轮 13 问，Q1–Q13 用户全部按推荐确认）
- 关联：ADR-0003（**页面腿翻案**：「界面层统一 amis 单方言」的页面条款退役；对象/流程/治理轨道不变）、ADR-0004（studio 定性 = AI-first 结构性保障 + 人工二次修改能力，本 ADR 以可编辑代码工作台落实）、`docs/research/RESEARCH-appsmith-benchmark-platform-direction-2026-10-11.md` 候选 C9（被本 ADR 吸收）
- 性质：纯决策轮（未动代码）；实现排期见「三、排期」

## 背景

用户提出两大方向问题：①AI Coding 已能把前端页面写得很好，是否不必用页面设计器方言约束 AI，只约束数据模型（落库字段），页面交给 AI 自由发挥，平台为 AI 写出的前端代码设计安全运行方案，进而删掉页面设计器模块；②流程如何做到 AI 自动生成、免人工配置，是否还需要流程方言（参考飞书 aPaaS 流程模块逆向调研 `apaas-reverse-engineering/` 8 文档），目标是「AI 可控的流程中心」。

事实底座（2026-11-05/07 代码级核实）：

- **数据面闸门今天只有 40%**：记录写路径唯一服务端校验是 D-002 三项（required/maxLength/unique，`record.service.ts:1127-1180`），**无未知字段白名单、无按类型校验**，schema 外字段可直写 data JSONB（`record.service.ts:624-686`，控制器显式关闭 whitelist）；此前靠 amis 方言在前面挡了一层。无论页面层走哪条路，补齐是硬前置。
- **页面栈仅 ~2.4k 行**：studio 设计器 ~1600 + AmisRenderer 218 + G3 amis-page 校验器 296 + page-template 227。切换成本在重建「运行方案 + 治理对象」，不在删码。
- **embed 协议 v1 已随主干**（协议 187 行 + 桥 197 行 + 宿主 SDK 构建链），可作页面沙箱桥的模式母版。
- **方言税实证**：R6 挖出的两个生成质量缺口（crud 列 mapping 的 map 键、input-datetime valueFormat）本质都是「AI 不懂 amis 方言细节」；React/antd 是预训练母语，零教学成本；指南↔G3 一致性测试与组件白名单是永续维护税。
- **飞书印证**：飞书流程定义同为 JSON DSL 平图（activities+transitions、条件放边、fork/join 配对指针）与 WorkflowSchema 同构——流程方言形态是业界同款；飞书有「AI 描述生成流程」三通道创建、流程中心四视图（待处理/已处理/我发起的/抄送我的）、管理员干预（转交/撤销/退回）、intentSplit AI 意图分流一等节点。我们已有四视图中三个（2026-10-10 任务中心轮）。

## 决策

### 一、页面层翻案

1. **页面 = AI 自由写码 + 沙箱运行**；数据面合同成为唯一硬约束；amis 页面方言退役。G3 的 objects/processes/datasets/permission 四校验器不动，只退役 amis_page 一个。
2. **数据面闸门（前置条款）**：未知字段拒绝 400 + 明确错误（指明字段不在对象 schema）+ 按字段类型校验值（number/date/select 枚举/引用格式），create/update 双接入。否决静默剥离——AI 拿不到信号就无法自修正（G3 首拦同款闭环）。
3. **治理对象重定义**：页面制品 = {代码包，manifest}。manifest = 字段级读/写 × 操作（读列表/读详情/创建/更新）+ 可发起流程清单 + 页面元信息（slug/标题/菜单图标）；delete 默认不开放，真需求出现时显式申报扩容；manifest 兼作新 G3 页面校验器输入（引用闭合：声明的对象/字段/流程必须存在）。
4. **人审 = manifest diff + 沙箱渲染预览；代码本体不人审**。人工自写/自改代码提交 = 即时 APPROVED（草稿可改流语义对称）。
5. **运行时四层防线**：① 沙箱 iframe（不给 allow-same-origin）；② CSP 封死外联——数据只能走桥，页面物理上无法 fetch 任何非平台端点；③ **scoped page token** 按 manifest 发放、服务端强制（审批页发无写权 token——只读由服务端保证而非 UI 装样子；行级过滤继续由服务端权限层兜底）；④ 静态扫描（eval/外联）兜底。
6. **免构建受限运行时**：固定 React + **antd 5 单栈** + @apaas/design 素蓝 token + 平台封装组件（echarts/dayjs/桥 SDK）经 import map 供给；**禁任意 npm**——缺组件 = 组件库扩容走治理；发布时服务端 strip-types 转译缓存，页面源码即制品。禁 tailwind——单一样式系统承载平台一致性。
7. **审批动作归壳**：任务中心壳统一渲染审批操作条（意见输入 + 批准/驳回），绑定页只做只读详情展示，页面 token 无任何写权，completeTask 仅壳可调（延续「提交路径分离语义」：页面提交只写记录、流程推进仅任务中心）。
8. **人工通道**：studio 页面工作台 = Monaco **可编辑**代码编辑器 + manifest 面板 + 沙箱预览（修正第一轮 Q4 初稿「只读查看器」提法——按 ADR-0004 studio 定性应为可编辑）；人工改码提交即时 APPROVED。
9. **存量处置**：运行方案验证后，AI 一次性重写 seed 存量 9 页 + 模板生成器（page-template）改产新轨（即新轨首轮 dogfood，暴露的坑回流运行方案）→ **同波次物理删除** AmisRenderer / amis-editor 画布 / amis 依赖 / amis_page 校验器 / 方言指南页面节，零双轨期（零兼容原则）。

### 二、流程侧（不翻案，扩「AI 可控」）

10. **治理与方言零翻案**：WorkflowSchema 保留（飞书同款 JSON DSL 平图印证形态正确）；全环境人审保留（流程写库/发审批/发通知，爆炸半径与页面不同级）；目标「人工零配置、只裁决」；草稿环境免审自动生效列后续候选（配合 C7 dry-run 仿真）。
11. **AI 可控流程中心三件**：① MCP 工具面扩全生命周期（迭代已发布流程新版本、实例查询/取消/转交/催办、监控指标回流 agent 形成改进环）；② 流程中心补齐——通知节点消息打 cc 标签 →「抄送我的」视图（零引擎改动，现有节点注册表无抄送语义）+ 补「转交」端点（撤销已有、退回 = rejectToNodeId 已有）；③ flowgram 画布**保留可编辑**（人工改稿通道），审核中心默认以审阅姿态进入——人从「配置者」变「裁决者」。
12. 节点级抄送配置（抄送人/抄送节点类型）留后续候选；intentSplit 式 AI 意图分流节点并入候选 C8 评估。

### 三、排期

13. **数据面闸门小轮先行**（新轨安全前提且独立有价值）→ **PE-01~31 修缮按既定波次照走**（与页面轨零耦合）→ **页面新轨为下一主线大轮**（沙箱运行时 + manifest + G3 新校验器 + MCP 提交改造 + 存量重写 + 删设计器，预计 2-3 波）→ **流程中心三件作间隙轮**插入。

## 被否方案

- **页面层维持 amis 方言 + 持续教学 AI**：方言税永续（指南↔G3 一致性测试、166 组件白名单），R6 缺口为实证；React 是 AI 母语，教学成本不对称。
- **每应用构建管线（vite build + npm 全生态）**：隔离构建器/供应链扫描/分钟级构建/缓存治理重基建，与「不造轮子、简单稳定」原则冲突。
- **tailwind + shadcn 栈**：AI 生成顺手、视觉自由度大，但与素蓝 token、antd 既有资产两套体系；一致性退化后的载体越单一越守得住。
- **审批按钮入页面（经桥 completeTask）**：须给页面发含写权 token，AI 代码可编程推进流程，危险面大一个量级。
- **AmisRenderer 暂留过渡双轨**：违背零兼容原则，双轨期即双倍维护面。
- **未知字段静默剥离/剥离+告警**：AI 无信号自修正或两头不靠。
- **流程免审自动部署**：治理本体（ADR-0003）翻案，代价不成比例；草稿环境免审降级为后续候选。
- **流程改代码形态（删方言）**：无界爆炸半径 + diff 失锚 + G6 major 版本冻结承诺全塌；且 LLM 直出复杂结构不可靠的证据恰好支持「方言 + G3 + 指南」护栏形态。

## 后果与义务

- 平台一致性从 schema 保证退化为组件库约定——antd 5 单栈 + 素蓝 token 是守住它的唯一载体。
- AI 生成质量遥测口径随新校验器切换（G3 首拦率/一次通过率/返工率），实现轮重新定义基线，历史指标标注方言口径。
- 实现轮义务（红线 6/8 同提交）：TEST-CASES / QA-TEST-PLAN-PROMPT 随新轨落地同步更新（TC 编号延续现库尾号）、新轨 e2e、方言指南页面节删除时同步 MCP `submit_app_drafts` 页面制品类型换壳、embed 桥与沙箱桥的共享契约沉淀进 `@apaas/shared`。
- C9（sandbox_block）标记被本 ADR 吸收：新页面运行时即其平台级实现，amis 组件形态随方言退役。
