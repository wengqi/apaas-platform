### 1.3 表单组件与表单生成器（核心）

表单组件结构：`form` = 顶部区（block：表单标题文本）+ 内容区（formBody）+ 底部区（block：提交按钮），
另有「智能填表」AI 按钮（本期不做）。内容区空态文案：「拖入组件搭建，或使用 表单生成器」。

**表单生成器弹窗**（表单属性面板入口 / 内容区空态入口）：

- 来源：对象（选择业务对象）。
- 字段表格，列：`勾选 | 字段 | 类型 | 标题(可编辑) | 输入组件(类型映射，可选) | 必填(可勾选)`，
  每行带拖拽手柄可排序；系统字段（_id/_name/_status/_createdBy/...）展示但默认不勾选，
  `_name` 与 `_status` 必填锁死。
- 底部提示「将自动生成：N 个组件以及 1 个数据请求」+「生成表单」主按钮。
- 生成结果：勾选字段 → 对应输入组件（`_id`→数字输入、`_status`→下拉单选、关联对象→人员选择、
  日期时间→日期时间选择…），同时自动创建数据请求 `create<对象>.trigger()` 并接线到表单
  「提交时」事件（事件面板显示「提交时 → 调用数据请求 createDepartment.trigger()」）。

### 1.4 属性面板（右侧，单列滚动分组）

- 头部：面包屑组件路径（`page > form1 > formBody > numberInput`）+ 组件 ID 行内编辑。
- 分组标题（不是 Tabs）：**内容 / 交互 / 布局 / 尺寸 / 样式**（字段组件多一个 **风格** / **校验**）。
- 通用交互项（表达式输入框，默认值 false）：只读 / 禁用 / 加载中 / 隐藏。
- form 容器：初始值、结构（顶部区/内容区/底部区）、自定义表单校验、事件（提交时）、AI 能力（不做）。
- formBody 布局：布局类型（弹性/块）、布局方向、超出换行、网格间距、主轴/交叉轴对齐。
- 布局：位置类型（默认 Static）；尺寸：填充父容器开关、宽度（12 栅格）、高度（Auto 适应）、
  外边距、内边距。
- 样式：背景色/边框色（色值 + 透明度%）、边框粗细/虚实、圆角、阴影（色 X Y 模糊 拓展）。
- 字段组件（numberInput 示例）：默认值、占位符、数据格式（数值/百分比）、小数位数、空时值为 0、
  拓展（标题）；form data key（绑定字段 apiName）；校验（必填开关/最大值/最小值/自定义）；
  风格（输入框边框样式 线框/下划线、步进按钮、清空按钮、千位分隔符…）。
- select 字段：数据来源（系统选项集/自定义）、数据（选项集）、默认值、允许搜索、选项样式。

### 1.5 画布交互

- 选中组件：1.5px 蓝色边框（#1456f0 系）+ **上方浮动工具条**（蓝色胶囊：
  组件类型名 + 数据绑定/JS 图标 + 复制 + 删除 + 隐藏）+ 左右宽度手柄。
- 拖拽：物料 → 画布放置；画布内节点可拖拽排序；宽度可横向 resize（12 栅格）。
- 字段渲染：label 在上（必填红星）、控件在下；未绑定值显示 `--`。
- 页面设置弹窗：名称* / ID（URL 拼接）/ API 名称*（权限判断）/ 描述 / URL 参数 /
  关联移动端页面 / 导航栏显示配置 / 标签页图标 / 预览卡片。
- 状态数据页签：数据请求 / 自定义变量 / JS 方法 / 组件状态 / URL 参数。
- 大纲树页签：可搜索的组件层级树。

## 三、重设计方案

### 3.1 范围与原则

- **范围**：studio 页面设计器整体外壳 + 表单页全链路（表单生成器 → 字段属性 → 画布交互 → 大纲树）。
  飞书独有/生态项（双端独立配置、多语、全局代码、AI 组件、页面底部品牌标识）不做。
- **原则**：`PageSchema`/`ComponentNode` 契约与既有页面**完全向后兼容**（新 props 全部可选、
  默认值保持旧行为）；组件元数据 `COMPONENT_META` 仍是单一数据源，只新增分组与字段属性描述。

### 3.2 功能映射（飞书 → 本平台）

| 飞书 | 本平台实现 | 说明 |
|---|---|---|
| 顶部「设置」 | 页面设置弹窗：名称/ID(apiName)/类型/描述 | ID 直接用 apiName（URL slug） |
| 顶部「历史」 | 撤销/重做按钮 + 「已保存/未保存」状态文案 | 本地历史栈（50 步），无服务端保存点列表 |
| 顶部「刷新页面」 | 放弃本地修改并从服务端重载（脏状态需确认） | — |
| 顶部「预览/提交/发布」 | 预览（编辑/预览切换）/ 保存 / 发布 | 语义一致 |
| 桌面端/移动端 | 仅桌面端 | 移动端不在本期 |
| 物料分组 | 常用/布局/数据展示/数据输入/通用（按现有 29 组件重分组），4 列图标卡 | 组件集小于飞书，分组结构对齐 |
| 表单生成器 | `FormGeneratorModal`：对象选择 + 字段表格（勾选/标题/输入组件映射/必填/拖拽排序）→ 生成表单节点 + record 变量 + onSubmit 接线 `create_record` | 数据请求对应我们的 `vm.record` + 动作链 |
| form data key | 字段 `apiName` prop（生成时写入，面板只读展示）+ 绑定 `vm.record.{apiName}` | — |
| 字段属性分组 | 内容(标题/占位符/默认值/帮助文本/选项) / 校验(必填/长度/最值/精度) / 交互(只读/禁用/隐藏) / 尺寸(宽度 12 栅格 span) | — |
| 右侧单列分组 | 面包屑 + 单列滚动：专属配置 → 内容 → 校验 → 事件 → 数据绑定 → 样式 | 取消 Tabs |
| 画布工具条 | 蓝胶囊(图标+类型名 + 复制 + 删除)，选中 1.5px #1456f0 边框 | 左右 resize 手柄不做（span 数值输入替代） |
| 画布内排序 | 同父节点 dnd-kit sortable 接线 `reorderSibling` | 跨容器拖拽暂不做 |
| 大纲树 | 左侧页签「大纲树」，可搜索、点击选中 | 状态数据/代码页签不做（保留 ViewModelPanel 抽屉） |
| 画布宽度 | 960px 白卡 + 灰底 | 缩放移入顶栏 |

### 3.3 数据与文件设计

- 新增 `packages/studio/src/components/page-builder/form-generator/`：
  - `mapping.ts`：`fieldToComponentOptions(field)` 字段类型 → 候选输入组件（纯函数）；
  - `generate.ts`：`FormGenRow`(勾选/标题/组件/必填) + `buildFormNodes(rows, opts)` →
    `{ fieldNodes, viewModelPatch, onSubmitAction }`（纯函数，可单测）；
  - `FormGeneratorModal.tsx`：UI（对象 Select + 字段表格 + 拖拽排序 + 生成）。
- store 新增动作（均入历史栈）：`replaceChildren(parentId, children)`、
  `ensureRecordVariable(objectId)`（幂等写入 `vm.record` + datasource.objectId）、
  `reorderSibling(activeId, overId)`（同父排序）。
- 属性面板重构：`PropertyPanel.tsx`（面包屑 + 分组骨架）+
  `property-sections/FieldPropsSections.tsx`（内容/校验/交互/尺寸）。
- 画布：`Canvas.tsx`（960 卡片、顶栏缩放）、`ComponentRenderer.tsx`（胶囊工具条 + sortable）。
- 左栏：`LeftPanel.tsx`（组件/大纲树页签）+ `OutlineTree.tsx`；`ComponentPanel.tsx` 重排为
  飞书分组 4 列卡。
- 顶栏：`BuilderToolbar.tsx` 重构（页面设置弹窗 / 撤销重做 / 状态文案 / 预览 / 保存 / 发布 / 刷新）。
- 共享渲染层：`FormFieldItem` 支持 `span`(1-12，默认 12) 字段宽度 —— 默认值下渲染结果与旧版一致。

### 3.4 兼容性影响

- 旧页面 schema 不迁移、不改语义；新 props（`span`、字段 `apiName`、form `onSubmit`）均为可选。
- e2e 03-page-builder 为 API 级断言，不受 UI 重构影响；新增 UI 断言走 `data-testid`。

## 四、验收标准

1. 表单页：选中表单组件（或表单空态）可打开表单生成器，勾选对象字段、改标题、换输入组件、
   勾必填、拖排序，生成后画布即时呈现字段，保存后运行时可填写提交创建记录。
2. 字段属性：画布选中任一字段，右侧展示 内容/校验/交互/尺寸 分组，修改即时生效。
3. 画布：字段/组件可拖拽排序；选中显示蓝色胶囊工具条（复制/删除可用）。
4. 左栏：组件/大纲树两页签可用；物料为飞书式分组 + 4 列图标卡 + 搜索。
5. `pnpm lint / typecheck / test / build` 全绿，e2e 回归通过；文档同步（ROADMAP/STATUS-MATRIX/知识库）。
