# R-A 数据面写路径闸门实现记录（2026-11-07）

- 性质：ROADMAP **R-A 数据面闸门小轮**落地，ADR-0006 排期第一站完成

## 一、交付内容

**闸门（`apps/gateway/src/record/record.service.ts`）**：
1. **未知字段拒绝**：create（`filterWritableFields` 后）/ update（AutoNumber 剥离后、merge 前，只校验增量）双接入；400 消息列出未知键 + 可用字段名（截断 5 个 + 总数），供 AI 自修正。
2. **按字段类型校验值**：number/currency/percent（finite number）、single_select/multi_select（`optionStoredValue` 值域）、checkbox（严格布尔）、date/date_time（`Date.parse` 刻意宽松）、user/lookup/attachment（格式）、text 族（既有 maxLength 保留）。三重豁免按序：null → `''` 非文本视同空（与 D-002 isEmpty 口径对称）→ update 存量回显豁免（studio 编辑抽屉全量回显，存量 CSV 脏形状不阻塞合法编辑）。
3. **平台键剥离**（ADR「拒绝」语义的显式例外）：`id/version/createdAt/updatedAt/createdBy/updatedBy/tenantId/appId/objectId/environmentId` 写入前静默剥离，命中业务字段 apiName 不剥（apiName 白名单允许这些名字，防碰撞）；修复系统键落 data JSONB 的既有污染。
4. **fields 空数组守卫**（评审 B1）：bundle 缺失态（发布后新建对象）跳过校验 + warn 日志——「未发布对象禁写」是产品语义变更，不顺手做。
5. **计算字段不拦**（现状锚定）：AutoNumber/Formula/Rollup 用户传值 create 被覆盖/update 被剥离，本就不落库；硬拒绝列后续收紧候选。

**CSV 导入逐列强转（`record-import-export.service.ts`）**：number/currency/percent `Number()` 强转（失败整行剔除进 errors）、checkbox true/false 强转、multi_select 逗号切分、attachment 显式行错误（替代静默写垃圾串）、`''→null` 先于强转（避 `Number('')=0`）。已知边界：multi_select 逗号 round-trip 依赖选项无逗号（导出侧 `join(',')` 同构限制）。

**不做（边界，设计 §2.5）**：引擎管辖字段（审批状态）的用户直写拦截（R-C manifest 治理）、user 存在性校验、seed 直连 Prisma 路径。
