# Phase 10.4 — 完整 Demo 应用（资产管理系统）实现记录

> 完成日期：2026-08-23
> 验收标准（ROADMAP）：从零搭建含对象/页面/审批流程/权限/仪表盘的完整应用

## 概述

在现有 `asset_management` 应用壳（seed 已创建，status=DRAFT）中填充完整的业务内容，验证 aPaaS 平台所有核心能力（对象建模、页面搭建、流程引擎、仪表盘、应用发布）端到端可用。

## 架构决策：直接 DB 种子

选择扩展现有 `packages/db/seed.ts`（新增 `packages/db/seed-demo.ts` 模块），而非 API 驱动方案。理由：

1. 现有 seed 已创建应用壳，在同一脚本中填充内容最自然
2. seed 脚本在 `runAsSystem()` 中运行，可跨租户直接写入，不受 $extends 租户隔离影响
3. 幂等可重跑（upsert + 存在性检查）
4. 发布操作直接构造 `publishedSnapshot`（参照 `snapshot.service.ts` 格式）

### 1 个审批流程

**流程名**：资产领用审批（`asset_borrow_approval`）
**触发方式**：`RECORD_CREATED`（领用申请记录创建时自动触发）

```
start → user_task(审批) → condition(决策分支)
  ├── APPROVED → object_operation(更新资产状态) → notification(通知) → end
  └── REJECTED → notification(通知) → end
```

- `user_task`: assignee=admin 用户，taskName="资产领用审批"
- `condition`: 两条出边，基于 `decision` 值路由
- `object_operation`: operation=update，更新资产状态为 IN_USE
- `notification`: channel=IN_APP，通知申请人

### 24 条示例记录

- 资产分类：4 条（IT设备 / 办公用品 / 家具 / 车辆）
- 资产记录：15 条（覆盖 4 分类、4 状态、不同采购日期和价格）
- 领用申请：5 条（覆盖待审批/已批准/已拒绝状态）

### 应用发布

- `status` → `PUBLISHED`
- `version` → `1`
- 所有 `PageMeta.isPublished` → `true`
- 所有 `ProcessDef.status` → `PUBLISHED`
