# G6 纯流程 API 实现记录（2026-10-01）

> ROADMAP G6 / ADR-0003 决策 4：「纯流程（headless）：API 触发器 + API Key/服务身份 + 流程版本稳定性承诺——外部系统对接 v1 时，平台发布 v2 不得破坏 v1 契约」。ARCHITECTURE §7.2：「对外触发 API 绑定 major 版本，minor/patch 发布不破坏 v1 调用方」。

## 1. 三要素

### 服务身份（ServiceIdentity）
- 外部系统以 `X-API-Key: ak_...`（24 字节随机 hex，192 位熵）调用 `/api/v1/open/*`
- **库中仅存 sha256(key)**（unique 直查），明文仅创建响应返回一次；keyPrefix（前 12 位）供列表识别
- 校验失败统一 401 脱敏（不区分不存在/吊销）；`lastUsedAt` fire-and-forget
- 限流：独立 `open` 桶（`THROTTLE_OPEN_LIMIT`，默认 120/min）；JWT 管理面 CRUD 沿用 PAGE/MANAGE 口径 + `SERVICE_IDENTITY_CREATE/REVOKE` 审计

### API 触发器（OpenApiController）
- `POST /open/apps/:appId/processes/:apiName/start`（最新 ACTIVE major）
- `POST /open/apps/:appId/processes/:apiName/major/:major/start`（钉版本）
- `GET /open/apps/:appId/processes`（可调流程发现）
- 请求体 `{ inputs?, triggeredByUser? }`；inputs 展开到流程变量顶层（与记录触发一致，边条件可直接引用）；响应 `{ instanceId, processApiName, majorVersion, status:'RUNNING' }`
- 合成身份：ApiKeyGuard 校验后写 `request.user`（tenantId 供 ALS/环境上下文；`?env=` 照常生效）
- 审计 `PROCESS_API_START`：detail 只记 inputs 键名不记值（脱敏）

### 版本稳定性承诺（ProcessApiRelease）
- `apiName + majorVersion → 冻结 workflowSchema`，**发布后永不修改**
- 发布前置：活表 PUBLISHED 且 triggerType=API；重复 major 拒绝（不可覆盖）
- 新 major 时对上一 major 冻结快照跑 `diffProcessResource`（结构化 diff 随响应返回，破坏性变更半自动）；旧 major 自动置 DEPRECATED 但**仍可调用**（承诺本体）
- 执行：引擎 `startProcess` 新增 `schemaOverride` 入参——钉版本调用直通冻结 schema（def 行仅作 FK/元信息）；在途实例由 `frozenWorkflowSchema` 双保险
- 验证（e2e 19）：v2 发布（schema 变更 + diff 非空）后，`major/1/start` 仍 201 且按 v1 契约执行

## 2. 安全边界与明确不做

HMAC 请求签名（webhook 先例保留，API Key 熵足够 v1）；OAuth2 client_credentials 入站；scope 级授权（key 全权代表应用）；破坏性变更硬拦截（半自动 diff）；用量计费/配额。

## 3. 踩坑

1. **PermissionModule 导入坑第三次出现**：挂 PermissionGuard 的控制器所在模块（OpenApiModule）必须 imports PermissionModule——已记入知识库（R1.2 首记，G6 再证）。
2. e2e helper 默认参数让"无 key"用例落到有效 key：显式传 `''` 才省略 header。
3. Nest 路由段 `:apiName/v:major` 不可靠（path-to-regexp 段内字面量+参数）——用独立段 `major/:major`。

## 4. P1 轨道收官

G6 为 ADR-0003 蓝图 P1 最后一项。G3 校验合同 → G4 MCP（AI 出稿）→ G1/R1.2 版本模型（人审闸门）→ R1.4 多环境（发布=切指针）→ G5 数据下沉（引擎 SQL 化）→ **G6 纯流程 API（headless 契约）**——治理轨道 + 产品化轨道全部闭环。
