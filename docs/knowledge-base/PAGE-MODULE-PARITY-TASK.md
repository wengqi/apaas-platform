### 1.5 底部调试面板（批次A 目标，飞书实测结构）
- 页签：**错误检查(n) / 控制台 / 请求时间轴 / 性能(n) / 更多** + 右侧收起 X
- 错误检查：空态插画；列出 schema/运行时错误（计数徽标）
- 控制台：过滤条件（❌错误 ✓成功 ⚠警告 ℹ信息 计数 + ☑展示时间戳 + 清空）+ REPL 输入行（`>` 提示符）+ 日志流（语法高亮，如 `utils.toast.info("Hello, World!")`）
- 请求时间轴：按时间列出运行时 API 请求（空态为空）
- 性能：筛选 + 分组:问题类型 + 组件与代码块总数(n) + 查看最佳案例 + 空态插画
- 更多：更多调试工具入口

### 1.6 状态数据页签（批次B 目标，飞书实测结构）
- 搜索框 + 分组树：**数据请求**（每项可展开运行时状态树：type/id/data(返回数据)/error(错误信息)/loading(加载中)）、**自定义变量**（变量名+类型+当前值，可增删）、**JS 方法**（页面级 JS 函数列表）、**组件**（每个组件的运行时状态树 { } n keys）、**URL 参数**

### 1.7 物料「模板 / 自定义」页签
