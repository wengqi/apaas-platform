## 一、产品定位与核心理念

### 1.1 产品定位

飞书 aPaaS 定位为「新一代企业智能系统开发平台」，核心理念是「要低代码，不要低能力」。它不仅仅是一个拖拽生成页面的工具，而是一套完整的低代码工具箱，让用户无需编写复杂代码就能快速搭建在飞书内运行的、能管理数据和跑流程的业务系统或应用。

### 1.2 核心能力概述

| 能力维度 | 规格指标 |
|---|---|
| 单对象数据容量 | 2000 万行（官网）/ 1000 万行（架构文） |
| 单应用对象数 | 2000+ 个 |
| 页面组件数 | 130+ 个组件 + 海量模板 |
| 流程节点数 | 150+ 种节点类型 |
| 流程编排能力 | 单应用可编排 700 个流程，实现百万级代码效果 |
| API 集成 | 2000+ API |
| 合规认证 | 15 个权威合规认证 + 网络安全等级保护三级 |

### 1.3 五大核心功能支柱

1. **页面展示**：创建用户操作界面（表单、看板、卡片等）
2. **数据维护**：建立数据表，管理业务数据（如客户信息、项目记录）
3. **流程创建**：搭建自动化审批、通知和任务流转的业务流程
4. **集成连接**：连接飞书内外系统（如飞书消息、MySQL、HTTP 等）
5. **应用权限**：精确控制不同员工对数据和功能的访问权限

### 1.4 架构哲学

飞书 aPaaS 采用**模型驱动、低代码架构**，分层如下：

| 层 | 职责 |
|---|---|
| 数据层 | 对象（直接创建的实体）+ 数据集（数据流加工后的物化数据） |
| 逻辑层 | 流程引擎（触发器/分支/持久化/代码节点）+ 事件系统（JS 扩展） |
| 表现层 | 拖拽式页面搭建器，PC/移动端同步，图表 + 自定义组件 |
| 集成层 | 深度绑定飞书组织架构/消息/应用生态 + OpenAPI 凭证管理 |
| 治理层 | 多粒度 RBAC + 环境隔离 + 运营报表 |

> **使用门槛提示**：飞书 aPaaS 使用门槛稍高，需要有研发背景更容易上手，定位偏向 pro-code/low-code 混合体而非纯无代码。

## 二、完整功能模块清单

### A. 对象与数据建模

#### A.1 对象管理

| 功能项 | 描述 | 交互模式 | 关键配置项 |
|---|---|---|---|
| 创建对象 | 直接新建业务实体，定义 Schema 后即可 CRUD | 表单填写：显示名 + API 名 + 图标 + 描述 | apiName（snake_case）、label、icon、description |
| 编辑对象 | 修改对象的显示名称、图标、描述等 | 内联编辑或表单 | label、icon、description |
| 删除对象 | 删除前校验：存在记录/被关联/被引用时阻止 | 二次确认弹窗 | — |
| 对象列表 | 按应用列出全部对象 | 左栏列表，显示名称/记录数/字段数/更新时间 | 搜索、排序 |
| 对象详情 | 展示字段列表、视图列表、记录入口 | 主从布局：左列表 + 右详情 | — |
| 复制对象（结构） | 复制字段定义到新对象，不复制数据 | 操作菜单 | API 名加后缀 |
| 导出对象定义 | 导出对象 + 字段 + 视图为 JSON，跨环境迁移 | 操作菜单 | — |
| 对象图标库 | 内置线性图标集，按分类选择 | 图标选择器弹窗 | — |
| 主显示字段 | 决定记录在列表/关联选择器中的标题展示 | 下拉选择 | nameFieldId |
| 系统对象 | 内置对象（如 User/Org），不可删除 | 标记「系统」标签 | isSystem |

#### A.2 字段类型（20+ 种）

飞书 aPaaS 支持 20+ 类型字段，单表可容纳 1 亿行数据（官网最新数据）。

##### 文本类

| 类型 | 配置项 | 说明 |
|---|---|---|
| 单行文本 | 最大长度（默认 255） | 短文本，如名称、电话 |
| 多行文本 | 最大长度（默认 2000） | 长文本，如备注、描述 |
| 富文本 | 最大长度 | HTML 富文本，支持格式化编辑 |
| 自动编号 | 编号规则格式（如 `ORD-{seq:0000}`） | 系统按规则自动生成，不可编辑 |

##### 数值类

| 类型 | 配置项 | 说明 |
|---|---|---|
| 数字 | 小数位数（0-10） | 整数/小数 |
| 金额 | 小数位数 + 货币代码（CNY/USD/EUR） | 带货币符号展示 |
| 百分比 | 小数位数 | 按百分比展示与输入 |

##### 选择类

| 类型 | 配置项 | 说明 |
|---|---|---|
| 单选 | 选项列表（id/label/color/isDefault） | 选项互斥，可设默认项 |
| 多选 | 选项列表 | 可多选，值存数组 |
| 复选框 | 默认值 | 布尔值 true/false |

##### 日期时间类

| 类型 | 配置项 | 说明 |
|---|---|---|
| 日期 | 显示格式 | 仅日期，无时间 |
| 日期时间 | 显示格式 | 日期 + 时间，存 ISO 8601 |

##### 媒体与引用类

| 类型 | 配置项 | 说明 |
|---|---|---|
| 附件 | 最大数量 | 文件上传，值存文件元信息数组 |
| 人员 | 是否多选 | 引用系统用户，值存 userId 或 userId[] |

##### 关联与计算类

| 类型 | 配置项 | 说明 |
|---|---|---|
| 关联（Lookup） | 目标对象 + 关系类型 + 反向字段名 | 关联其他对象，值为目标记录 ID |
| 子表（SubForm） | 子对象 + 父关联字段 | 主从一对多，值为子记录数组 |
| 公式（Formula） | 表达式 + 返回类型 | 表达式计算，只读 |
| 汇总（Rollup） | 目标字段 + 聚合方式（sum/avg/count/min/max） | 聚合关联对象字段 |

##### 字段属性

| 属性 | 说明 |
|---|---|
| 必填（required） | 记录保存时校验非空 |
| 唯一（unique） | 全对象内值唯一 |
| 可搜索（searchable） | 标记参与全局/列表搜索 |
| 默认值（defaultValue） | 字面量或表达式（如 `{ __expr: 'NOW()' }`） |
| 描述（description） | 字段说明，表单中作为提示 |
| API 名称（apiName） | snake_case，创建后不可改 |
| 显示名称（label） | 可随时修改 |
| 字段级加密 | 字段级加密存储，保障数据安全 |

#### A.3 关联关系

| 关联记录选择器 | 录入时弹出目标对象的列表视图供选择 |

|---|---|
| 列表视图 | 表格形式，支持筛选/排序/分组/字段显隐/分页 |
| 详情视图 | 单条记录的只读展示布局 |
| 表单视图 | 新增/编辑记录的表单布局 |
| 看板视图 | 按单选字段分组的卡片看板 |
| 日历视图 | 按日期字段排布的日历 |

##### 列表视图能力

| 能力 | 描述 |
|---|---|
| 字段显隐与顺序 | 选择显示字段列、拖拽调整列顺序、调整列宽 |

#### A.5 系统字段（内置）

### B. 数据集与数据流

数据集是飞书 aPaaS 的两大亮点之一（另一个是流程编排），区别于直接创建的对象。

#### B.1 数据集（Dataset）

| 功能项 | 描述 |
|---|---|
| 实体数据 | 数据集是**实体数据**，不是视图——是经过数据流加工后的物化结果 |
| 生成方式 | 必须通过数据流处理生成，不能直接创建 |
| 与对象的区别 | 对象可直接创建并支持 CRUD；数据集需数据流加工 |
| 当前限制 | 页面表格组件目前只能绑定单表数据源，聚合场景需提前物化数据 |

#### B.2 数据流设计

| 功能项 | 描述 |
|---|---|
| 多表关联 | 支持多表 join 关联 |
| 分组汇总 | 支持分组聚合统计 |
| 数据筛选 | 支持数据过滤条件 |
| 输出数据集 | 处理结果输出为数据集 |
| 全局共享 | 选项和参数支持应用内全局共享 |

## 五、功能优先级建议

基于飞书 aPaaS 功能体系和当前平台差距，建议按以下优先级推进：

### P0 — 当前 Phase 1 必须完成

1. meta-svc 对象/字段/视图 CRUD 后端逻辑
2. runtime-svc 记录 CRUD + JSONB 动态查询
3. 视图配置器（筛选/排序/字段显隐）
4. 字段拖拽排序（dnd-kit 接入）
5. 选项管理器（单选/多选）
6. 记录列表查询 + 分页 + 筛选 + 排序

### P1 — Phase 1 尽量做 / Phase 2 前置

1. 记录导入导出（CSV/Excel）
2. 批量操作（批量删除/批量编辑）
3. 公式/汇总字段执行引擎
4. 页面搭建器 MVP（拖拽 + 组件树 + 属性面板 + 运行时渲染）

### P2 — Phase 2-3 范围

1. 页面搭建器完整版（事件系统 + 表达式绑定 + 视图模型）
2. 流程引擎自研执行内核
3. 流程双模式编辑器（简化 + 标准 BPMN）
4. 流程监控仪表盘
5. 人工任务/审批节点

### P3 — Phase 4-5 范围

1. 权限五级体系完整实现
2. 行级数据权限 + 字段级权限
3. 数据集与数据流模块
4. 连接器管理模块
5. 仪表盘/图表引擎
6. 应用发布快照与版本管理

### P4 — 后续迭代

1. 云函数平台
2. 自定义组件开发
3. JS 代码扩展
4. 组件市场
5. 运营报表
6. OpenAPI 凭证管理
7. 软删除/回收站
8. 行为追踪/审计日志
