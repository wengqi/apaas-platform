### 1.5 权限模块（/ae/permission/...?env=sandbox —— 沙箱环境参数）
- 菜单：**角色权限 / 记录权限 / 权限查询 / 权限设置**
- 角色 = 功能权限集合（能访问哪些页面、发起哪些流程、对哪些对象或数据集进行怎样的操作）；预置角色：**全部权限角色 full_access_role / 全局只读角色 global_reader_role**；角色有**启用开关**与**设置成员**
- **记录权限（行级）= 角色 × 记录范围（条件）× 可对记录进行的操作（查看/编辑/…）**，按对象逐一定义
- 对象编辑器另有**字段权限**入口（字段级授权）

- **API 凭证及事件**：API 凭证管理

## 三、差距分级建议（给本项目的行动清单）

**P0（对标核心体验，建议近期）**
1. **草稿/提交两级版本模型 + 历史版本**（当前"发布即版本"过于粗放，编辑丢失不可恢复）
2. **对象级搜索配置 + 字段显式索引/唯一配置**（数据模块补齐配置显式化）
3. **流程表单触发**（审批/人工任务流程的表单绑定与"保存草稿"按钮）
4. **流程效率分析**（流程中心：平均耗时/完成率/超时数——数据已有，缺聚合视图）

**P1（能力补强）**
5. 观测模块：函数执行/数据慢查询/OpenAPI 调用分类 + 事件链路（在 audit_logs 基础上扩展分类与追踪 ID）
6. AI 组件与 AI 生成页面/流程（低代码 + LLM 是飞书明确主航道，MCP Server 值得跟踪）
7. 系统对象（用户/部门）作为一等公民 + 对象关系视图（ER 图）
8. 审批人分环境配置、会签/或签/依次审批

**P2（远期/生态）**
9. 官方连接器市场、模板市场（方案中心）、共享库
10. 多语言、移动端适配、全局代码、页面级状态/代码
11. MCP Server（AI Agent 操作 aPaaS 的协议入口）

**本项目相对优势（实测确认）**
- 自研流程引擎的确定性执行（无付费墙的子流程/并行）；权限 ABAC 条件翻译到查询层（飞书记录范围为条件模型，实现深度未公开）
- 单体优先部署形态轻（飞书 aPaaS 免费版有对象数 5 个等硬配额）
- 全栈开源可控，可定制空间大
