## 3. 标准模式编辑器 (StandardEditor / bpmn-js)

| # | 用例名 | 前置条件 | 操作步骤 | 预期结果 |
|---|--------|---------|---------|---------|
| 3.1 | BPMN 画布初始渲染 | 切换到标准模式 | 观察画布 | bpmn-js 画布渲染所有节点为 BPMN 元素（startEvent/endEvent/serviceTask等），节点间有 sequenceFlow 连线 |
| 3.2 | BPMN 调色板展示 | 进入标准模式 | 观察左侧调色板 | 显示 bpmn-js 原生调色板（hand tool/lasso/start event/end event/gateway/task 等） |
| 3.3 | 节点渲染正确 | 流程有 start+delay+end 三节点 | 观察画布 | startEvent（圆形）+ serviceTask（矩形 delay）+ endEvent（圆形粗边），三者有连线 |
| 3.4 | 连线渲染正确 | 流程有 edges | 观察画布 | sequenceFlow 连线在节点间正确渲染，有箭头方向 |
| 3.5 | 节点标签显示 | 画布有节点 | 观察节点 | 每个节点下方显示名称标签（如"开始"/"结束"/"delay"） |

| 3.7 | XML 视图切换 | 在标准模式 | 点击"XML 视图" | 底部展开 XML 内容区域，显示完整 BPMN 2.0 XML |
| 3.8 | XML 复制 | XML 视图已展开 | 点击"复制"按钮 | XML 内容复制到剪贴板 |

## 已知问题（测试时需关注）

| 问题 | 影响 | 当前状态 |
|------|------|---------|
| FlowGram 导出可能丢失顶层 edges | 连线在模式切换后可能消失 | 已修复（从节点内部提取 + 保留原 edges） |
| 撤销/重做按钮无 onClick handler | 撤销重做功能不可用 | 未修复（TD-11） |
| 导出 Schema/BPMN 菜单无实现 | 导出功能不可用 | 未修复（TD-12） |
| NotificationTemplateManager 孤立未路由 | 通知模板管理 UI 不可达 | 未修复（TD-13） |
| 对象创建 API label→name 字段映射 | 无法通过 API 创建对象 | 未修复（pre-existing） |
