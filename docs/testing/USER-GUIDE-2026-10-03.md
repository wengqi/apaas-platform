# aPaaS 平台用户操作简易指引

> 面向两类角色：**搭建者/管理员**（Studio，端口 5173）与**业务用户**（Runtime，端口 5174）。
> 配套实测报告：`docs/testing/QA-REPORT-2026-10-03.md`

---

## 一、角色与入口

| 角色 | 入口 | 说明 |
|---|---|---|
| 搭建者/管理员 | `http://<host>:5173`（aPaaS Studio） | 建模、搭页面、配流程、发布应用、平台治理 |
| 业务用户 | `http://<host>:5174`（aPaaS Runtime） | 使用已发布应用：填表、审批、看台账 |
| 平台管理员 | Studio 顶栏「平台管理」菜单 | 观测中心、权限调试、审计日志（仅租户管理员可见） |

**登录**：三段式（租户标识 + 邮箱 + 密码）。
- 租户用户（含租户管理员）：租户标识**必填**（如演示环境填 `demo`），账号 `admin@apaas.dev / admin123`（管理员）、`user@apaas.dev / user123`（终端用户）。
- 平台超管：租户标识留空登录。
- 也可以走租户路由免填租户标识：`/t/demo/login`。

## 二、搭建者：从零交付一个应用（五步）

### 第 1 步：创建应用
应用列表 →「创建应用」→ 填显示名称（如「会议室管理」）→ 创建。
- API 名称会自动生成建议值（`app_xxxxxx`），语义化需求可手改，创建后锁定。

### 第 2 步：对象建模（业务数据结构）
应用侧栏「对象」→ 新建对象（如「会议室」）→「添加字段」选类型（文本/数字/单选/日期/人员/关联/公式等 18 类）→ 配置必填/唯一/可搜索。
- 常用系统字段（创建人/时间等）自动带出，无需手建。
- 「可搜索」打开的字段会出现在记录列表的关键词搜索范围。
- 「数据」页签直接录入/导入/导出记录，支持筛选与关键词搜索。

### 第 3 步：搭建页面（用户界面）
「页面」→ 新建页面 → 选类型（列表页/详情页/表单页/仪表盘/自定义），表单类页面可关联对象。
- **amis-editor 画布**：左侧物料面板（布局/表单/展示组件），拖入或点击添加；选中组件在右侧 Properties/Design/Event 配置属性、样式与事件。
- **代码模式**：顶栏「代码」直接编辑 amis JSON →「校验并应用」过平台 G3 校验 → 回画布所见即所得 →「保存」。
- **runtime 预览**：顶栏「runtime 预览」随时以用户视角打开当前页面。
- 注意：表单的提交按钮（submit/reset）是合法组件类型，保存校验放行。

### 第 4 步：编排流程（审批自动化）
「流程」→ 新建流程 → 进入流程画布。
- 画布默认「开始→结束」；**悬停连线点「+」**插入节点，节点分组：触发与起止 / 数据操作 / 流程控制（条件/包含/并行/循环）/ 业务操作（人工任务、通知、HTTP 请求等）。
- **人工任务（审批节点）**：任务名称 → 审批人类型（指定用户=成员搜索选择器，可多选做会签/或签；也支持角色/组织/上级主管/表单字段）→ 审批模式（单人/会签/依次→会签或签）→ 可选绑定任务表单（审批人处理时看到页面）。
- 节点未配置完会有红色「有未完成的配置」提示；配置完整后消失。
- 「保存」→ 流程「发布」（草稿→激活；G6 开放 API 场景走 api-release 冻结 major 版本）。

### 第 5 步：发布应用（版本 + 环境）
应用顶栏「发布」→ 三步向导：版本信息（版本号 + 目标环境：生产/仅开发）→ 变更内容清单 → 确认发布。
- 发布 = 生成版本快照并切换环境指针；运行时按环境读取。
- G4 闸门：必填环境变量未设值时会拦截发布，按提示到「环境管理」补值。
- 「发布历史」可一键回滚到任意历史版本。

## 三、业务用户：使用应用

1. 登录 Runtime →「我的应用」打开应用。
2. 顶部页签在应用内切换页面（如：合同提交 / 合同台账 / 合同审批页）。
3. **填表提交**：填写表单 → 提交（成功后有确认弹窗与下一步指引）。自动编号字段（如合同编号 PO-0001）由系统生成。
4. **处理审批**：「任务中心」→ 待办列表 →「处理」→ 弹窗内查看合同信息与流程轨迹 → 填审批意见 → **批准/拒绝**（弹窗底部按钮是唯一审批动作入口）。
5. 右上角可切换环境（生产/开发）、查看站内通知。

## 四、管理员：平台治理

- **观测中心**（`/platform/observability`）：云函数执行 / 慢查询 / 页面报错 / 开放 API 调用四类事件（最近 24h 统计 + 明细查询）。每条事件带 Trace ID，可复制用于排障串联；错误响应里也返回同一 traceId。
- **权限调试**（`/platform/permission-debug`）：选用户 + 资源类型/动作/目标 ID →「执行调试」→ 查看权限决策解释（有效角色、命中规则、deny-overrides 结论、合并条件、翻译后的行级 where）；填记录 ID 可额外验证该记录是否满足行级条件（注意：拒绝场景下该验证仅表示行级条件适配性，不代表可读）。
- **审计日志**：平台级（用户菜单）与应用级（应用侧栏）两个入口，支持按分类（应用生命周期/治理轨道/流程/数据记录/访问与权限）与操作类型筛选，含 Trace ID。

## 五、常见问题

| 问题 | 处理 |
|---|---|
| 登录 401 | 租户用户必须填租户标识（demo）；只有平台超管可留空 |
| 发布被拦截 | G4 预检：到「环境管理」给必填环境变量设值后重试 |
| 审批页字段显示 "-" | 数据域断裂——升级到最新版本（2026-10-03 已修，e2e/21 守护） |
| 表单页保存报未知组件类型 | 升级到 2026-10-03 之后版本（submit/reset 已入白名单） |
| 页面改完没生效 | 已发布应用读环境快照——重新「发布」新版本；开发期可切 `?env=dev` |
| 想撤销未发布的修改 | 应用「审核中心」可查看未提交变更并一键撤销（恢复基线快照） |
